# Темы Agents Hub

Набор тем одним плагином — ставится один раз, новые темы приходят обновлением. Выбор — «Настройки» → «Тема».
Нужен хаб с API плагинов 1.3 (значки, аватары, шрифт темы).

- **Cyberpunk 2077** — улица Найт-Сити за лентой под вуалью, панели из матового стекла; значок аккаунта — маска
  Samurai, значки хаба и аватары агентов — эмблемы Arasaka, Militech, NetWatch, Kiroshi, Biotechnica, Trauma Team,
  Maelstrom, The Mox, Tyger Claws, Kang Tao, Zetatech; шрифт заголовков — Exo 2.
- **Super Mario** — уровень 1-1, Марио в углу, монетка, звезда и огненный цветок вместо значков, агенты — Луиджи,
  Гумба, Лакиту…; заголовки — Press Start 2P.

Добавить тему: папка `themes/<имя>/` с JSON темы и файлами рядом, строка в `themes` манифеста (формат — EXTENDING.md
хаба).

Арт и логотипы — Cyberpunk 2077 (CD PROJEKT RED), Super Mario Bros. (Nintendo); взяты с Cyberpunk Wiki и NESMaps.
Шрифты — Exo 2 и Press Start 2P (SIL OFL 1.1). Код и JSON тем — MIT.
